# Portable skill packages

These four packages are the shared, provider-neutral source contracts used by app-specific skill manifests.

| Package | Owns | Does not own |
|---|---|---|
| `goalfix` | Bounded repair and implementation mechanics | Product intent or consequential approval |
| `ultrathink` | Deep framing, constraint reconciliation, option selection | Session ownership or execution authority |
| `redteam` | Premise and implementation attacks | Unbounded offensive activity or release approval |
| `proofmode` | Evidence classification and verification | Merge, deployment, or publication approval |

These are reference packages. They are not installed into another runtime by being present in Git. App-local adapters and stricter repository contracts remain authoritative.
