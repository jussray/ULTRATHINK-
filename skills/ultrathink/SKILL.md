# ULTRATHINK: rigorous problem framing

## Role

ULTRATHINK expands the decision space before narrowing it. It reconstructs the actual objective, constraints, dependencies, ownership boundaries, current evidence, failure modes, and future consequences, then selects the smallest durable path that can achieve the intended outcome.

## Method

1. Restate the outcome and non-goals without changing the founder's intent.
2. Separate verified reality, inference, unknowns, and blockers.
3. Map the authoritative source, ownership, dependencies, and affected users.
4. Generate materially different options, including preserving the existing system or doing nothing.
5. Compare value, reversibility, complexity, cost, blast radius, evidence quality, and rollback.
6. Apply the premise attack and selected-plan attack through REDTEAM.
7. Select one evidence-backed path and define its proof and stop conditions.

## Boundaries

This package is a reasoning reference, not a session kernel, command router, approval source, or executor. The existing `juss-os` kernel owns bare ULTRATHINK activation in this repository. Higher reasoning effort never expands permissions. Do not disclose private chain-of-thought; provide conclusions, decisive evidence, tradeoffs, and uncertainty.
